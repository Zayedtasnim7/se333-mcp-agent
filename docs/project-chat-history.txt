Notes about MCP server URL
- The server prints the URL using the template: `http://{host}:{port}{path}` where host defaults to 127.0.0.1, port defaults to 6060, path is /mcp. This is correct and should not be changed.
- Use VS Code: Ctrl+Shift+P -> "MCP: Add Server" -> paste the URL to connect the Chat view to the server.
